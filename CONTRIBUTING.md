# Contributing to filoAI

Thank you for your interest in contributing!

## Before starting

1. Check existing issues and pull requests to avoid duplicated work.
2. For substantial changes, open an issue to discuss the approach first.
3. Never include private documents, credentials, API keys, or local `.env` files in a contribution.

## Local setup

```bash
git clone https://github.com/VipinKumar04/FiloAI.git
cd FiloAI
npm install
npm test
npm start
```

## Contribution guidelines

- Keep changes focused and explain their purpose.
- Follow the existing project structure and JavaScript conventions.
- Add or update tests for behavior changes.
- Run `npm test` before opening a pull request.
- Update the README when setup, behavior, or supported functionality changes.
- Treat all AI-generated output and client-supplied paths as untrusted.
- Do not introduce file deletion or modification behavior without explicit review and tests.

## Pull requests

Include:
- A concise summary of the change.
- The reason for the change.
- Test commands and actual results.
- Screenshots for significant UI changes, if useful.

Be respectful and constructive in reviews and discussions.
